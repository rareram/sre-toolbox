# Node Exporter 설치 도우미

이 폴더는 서버의 기본 리소스(CPU, 메모리, 디스크, 네트워크 등)를 모니터링하는 Node Exporter 설치용 스크립트입니다.

## 파일 구성
* `installer.sh` - 설치, 삭제, 관리를 처리하는 대화형 스크립트
* `backup/` - 구버전 스크립트 보관 폴더

## 수집 모드 선택 가이드
설치 시 상황에 맞게 2가지 수집 모드 중 하나를 선택할 수 있습니다.

### 1. 전체 수집 (Standard)
Node Exporter의 기본 수집기를 모두 활성화합니다. 서버 대수가 적고(수십 대 이하) 세부적인 커널 지표나 파일시스템 상세 정보까지 확인해야 할 때 적합합니다.

### 2. 경량 수집 (Lightweight)
대규모 서버군(수백 대 이상)을 모니터링할 때 권장합니다. CPU, 메모리, 디스크 사용량, 네트워크 같은 핵심 지표는 그대로 수집하되, 수집 항목이 많아 모니터링 서버(Prometheus)의 용량을 많이 차지하는 비핵심 지표들을 제외합니다.

**제외되는 주요 수집기:**
* `arp` (대형 네트워크 환경에서 메트릭 폭증 유발)
* `nfs`, `nfsd` (NFS 마운트 정보)
* `wifi` (무선 네트워크 상세 지표)
* `zfs` (ZFS 파일시스템 지표)
* `ipvs` (IPVS 로드밸런싱 지표)
* `entropy` (시스템 엔트로피 상태)
* `bcache` (블록 캐시 지표)
