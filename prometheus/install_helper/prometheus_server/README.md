# Prometheus Server 설치 및 관리 도우미

이 폴더는 Prometheus Server의 설치, 마이그레이션, 백업 및 스냅샷 관리 등 운영 전반을 돕는 스크립트입니다.

## 파일 구성
* `installer.sh` - Prometheus Server 설치 및 관리(스냅샷, 마이그레이션 등)를 처리하는 대화형 스크립트
* `backup/` - 구버전 스크립트 보관 폴더

## 주요 기능
스크립트를 실행하면 대화형 메뉴를 통해 다음과 같은 서버 관리 기능을 사용할 수 있습니다.

### 1. 스냅샷 및 스토리지 관리
* **스토리지 상태 확인**: Prometheus TSDB 스토리지의 디스크 사용량 및 파일 구성을 검사합니다.
* **스냅샷 생성 및 조회**: 데이터 백업이나 이전을 위해 실시간 데이터 스냅샷을 생성하고 보관된 목록을 확인합니다.

### 2. 패키지 마이그레이션
* OS 패키지(YUM/APT 등)로 설치되어 운영 중이던 Prometheus 환경을 바이너리 실행 본으로 안전하게 전환합니다. 기존 설정 파일과 데이터 디렉토리를 자동으로 감지하고 보존하며 마이그레이션을 진행합니다.

### 3. 바이너리 관리 및 버전 업데이트/롤백
* 특정 버전을 입력하여 Prometheus 버전을 쉽게 올리거나 내릴 수 있습니다.
* 설치 과정에서 다운로드되어 보관 중인 옛 바이너리 파일들을 정리하여 디스크 공간을 확보할 수 있습니다.

### 4. TSDB 동기화
* 데이터 정합성을 위해 TSDB 스토리지 상태를 점검하고 동기화 처리를 수행합니다.

---
* Prometheus 상세 설정 및 튜닝법은 [Prometheus 공식 문서](https://prometheus.io/docs/introduction/overview/)를 참고하세요.
