# 윈도우 프로메테우스 에이전트 자동 설치 프로그램 (`win_exp_inst`)

윈도우 서버 여러 대에 프로메테우스 모니터링 프로그램(windows_exporter)을 마우스 클릭 몇 번으로 쉽게 설치하고 서비스로 등록해 주는 프로그램입니다.

---

## 🤔 어떤 상황에서 쓰나요?

1. **윈도우 서버가 너무 많아서 일일이 켜기 귀찮을 때**:
   - 서버마다 다른 버전을 설치하면 나중에 관리가 안 되므로, 검증된 동일한 버전으로 통일해서 깔고 싶을 때 씁니다.
2. **서버가 재부팅되면 모니터링이 꺼질까 봐 불안할 때**:
   - 단순 실행이 아니라 윈도우 시스템 서비스(Service)로 정식 등록해 주므로, 서버가 재시작되어도 자동으로 모니터링 프로그램이 다시 켜집니다.
3. **명령어 입력이 어렵고 실수를 줄이고 싶을 때**:
   - 마우스 클릭 방식의 설치 화면을 제공하여 누구나 실수 없이 쉽게 설치 및 제거할 수 있습니다.

---

## 🛠️ 컴파일 및 실행 파일 만드는 방법

개발용 컴퓨터에서 프로그램(.exe) 파일 하나로 묶어낼 때 사용합니다.

```bash
# 1. 필요한 패키지 설치
pip install -r requirements.txt

# 2. 단일 실행 파일(.exe)로 빌드하기
pip install pyinstaller
pyinstaller -F --noconsole --add-data "github_icon.png;." --add-data "logo.png;." wexporter-installer.py
```

## 🛡️ 적용된 주요 보안 업데이트

프로그램이 더 안전하게 동작하도록 최신 라이브러리 보안 패치를 완료했습니다.
- `urllib3` (2.7.0): 다운로드 중 악의적인 압축 파일로 인한 서버 멈춤 방지
- `setuptools` (83.0.0): 파일 경로 조작으로 중요한 시스템 파일이 덮어씌워지는 문제 방지
- `requests` (2.33.0): 다운로드 중 임시 파일이 외부로 누출되는 현상 방지
- `idna` (3.15): 특수 문자 처리 중 CPU 사용량이 100%로 치솟는 문제 방지
