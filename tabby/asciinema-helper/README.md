# Tabby 터미널 화면 녹화 플러그인 (`tabby-asciinema-helper`)

Tabby 터미널에서 내가 명령어 친 작업 과정을 화면 그대로 녹화해서 파일(.cast)로 남겨주는 플러그인입니다.

---

## 🤔 어떤 상황에서 쓰나요?

1. **원격 서버에 녹화 프로그램을 설치하기 부담스러울 때**:
   - 운영 중인 운영 서버에 프로그램을 함부로 깔면 안 될 때, 내 컴퓨터의 Tabby 터미널 프로그램 자체에서 화면을 직접 녹화하므로 원격 서버에 아무것도 설치할 필요가 없습니다.
2. **동료나 팀원에게 작업 과정을 영상처럼 보여주고 싶을 때**:
   - 텍스트 파일(.cast) 형태로 저장되므로 용량이 아주 가볍고, 명령어 친 내용이 그대로 기록되어 동료에게 쉽게 공유할 수 있습니다.
3. **실수로 비밀번호나 중요한 IP를 화면에 찍었을 때**:
   - 플러그인 내에 **민감정보 스캐너** 기능이 들어있어, 파일 저장 전에 비밀번호나 API 키를 별표(`***`)로 깔끔하게 가려서 안전하게 저장할 수 있습니다.

---

## 🛠️ 쉬운 사용법

1. Tabby 터미널을 켭니다.
2. 상단 툴바의 **녹화 시작** 버튼을 누릅니다 (단축키: `Ctrl + Shift + R`).
3. 서버에서 평소처럼 작업을 진행합니다.
4. 작업이 끝나면 **녹화 중지** 버튼을 누릅니다 (단축키: `Ctrl + Shift + R`).
5. 녹화 파일 경로가 클립보드에 자동으로 복사됩니다.
6. 파일 공유 전에 **Tabby 설정 > Asciinema** 탭을 열어 비밀번호나 IP를 가려주는 **민감정보 스캐너**를 한 번 실행해 주는 것이 좋습니다.

---

## 💻 설치 방법

### Tabby 설정에서 바로 설치하기 (추천)
1. **Tabby 설정** -> **Plugins** 메뉴로 들어갑니다.
2. `tabby-asciinema-helper`를 검색하고 **Install** 버튼을 누릅니다.
3. Tabby를 껐다 켜면 바로 사용할 수 있습니다.
