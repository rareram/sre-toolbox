# SRE 장애 상황 알림 봇 (`incident-comm-bot`)

서버에 장애가 났을 때 당황하지 않고, 클릭 한 번으로 **개발팀용 자세한 보고서, 팀장님용 짧은 요약 보고서, 고객용 상황 안내문**과 조치 순서(타임라인)를 자동으로 생성해 주는 유틸리티 프로그램입니다.

---

## 🤔 어떤 상황에서 쓰나요?

1. **갑자기 서버나 DB가 터졌을 때**:
   - 온콜 엔지니어가 메신저에 적은 무작서 로그나 간단한 상황 설명을 봇에 넣으면, 보고받는 사람(팀장님, 개발팀, 일반 고객)의 눈높이에 맞춰보고서를 알아서 다르게 텍스트로 만들어 줍니다.
2. **장애 조치가 길어질 때**:
   - 똑같은 장애 번호(`incident_id`)로 새 소식을 추가로 넘겨주면 "장애가 발생한 지 몇 분 지났고, 그동안 어떤 조치를 했는지" 타임라인을 알아서 차곡차곡 쌓아줍니다.
3. **무엇부터 점검해야 할지 막막할 때**:
   - DB 장애인지, 웹 서버 장애인지에 맞춰 "서버에서 이 명령어부터 실행해 보세요" 하고 점검 팁(플레이북)을 함께 알려줍니다.

## 🛠️ 쉬운 사용법

### 1. 설치하기
터미널에서 아래 명령어로 필요한 라이브러리를 설치합니다.
```bash
uv sync
```
(또는 `pip install -r requirements.txt`)

### 2. 설정 파일 만들기
`.env.example` 파일을 복사해서 `.env` 파일로 이름을 바꾸고, 사용할 LLM(Ollama 또는 OpenAI) 정보를 적어줍니다.
```bash
cp .env.example .env
```

### 3. 프로그램 켜기
```bash
uv run python app.py
```

## 📡 주요 기능 테스트하기

### 서버가 잘 켜졌나 확인 (`GET /healthz`)
인터넷 브라우저나 터미널에서 주소를 치면 봇의 상태를 보여줍니다.

### 보고서 자동으로 만들기 (`POST /generate`)
아래 예시처럼 상황 설명 한 줄만 보내면 봇이 보고서를 만들어 줍니다.
```json
{
  "raw_incident": "2026-07-24 12:00 DB 서버 응답 없음, 결제 지연 발생 중",
  "incident_id": "INC-PAY-01"
}
```
