# KeepLogin Hard Reload (v0.1.5)

> 현재 사이트의 로그인 쿠키와 세션은 보존하고, HTTP 캐시와 서비스 워커만 완전히 비운 뒤 강력 새로고침을 수행하는 크롬 확장 프로그램입니다.

---

## 1. 개요 및 핵심 가치

Grafana 브랜딩(배경 이미지, CSS 커스텀), 대시보드 리소스 수정, 또는 SSO(SAML/OAuth/OIDC) 연동 환경 테스트 시 일반 하드 리프레시(`Shift + Command + R`)로는 Service Worker 및 정적 번들 캐시가 갱신되지 않는 문제가 있습니다.

또한 브라우저 캐시를 일괄 삭제하거나 시크릿 창을 열 경우 로그인 세션이 끊겨 매번 재인증을 거쳐야 하는 피로도가 발생합니다.

**KeepLogin Hard Reload**는 이러한 문제를 해결하기 위해 다음을 보장합니다:
1. **정밀 타겟팅**: 전체 브라우저가 아닌 **현재 활성 탭의 도메인(Origin)** 데이터만 정리합니다.
2. **세션 안전 보장**: **Cookie, LocalStorage, IndexedDB**는 보존하여 로그인 상태를 100% 유지합니다.
3. **완전한 캐시 무효화**: HTTP 디스크/메모리 캐시, Cache Storage API, 그리고 Service Worker 등록을 초기화합니다.
4. **인-페이지 HUD 토스트**: 단축키/클릭 즉시 웹페이지 상단에 다크 캡슐 토스트 및 프로그레스 바가 노출되어 진행 상태를 실시간 시각화합니다.
5. **모던 대시보드 옵션창**: 다크/라이트 테마, 열린 탭 목록 파싱, 사용자 관리 도메인, 백그라운드 스케줄러를 지원합니다.
6. **AI 에이전트 연계 (Cross-Platform)**: 터미널 명령어 또는 에이전트 툴 콜(`curl` 등)로 브라우저 새로고침을 자동 트리거하는 로컬 브릿지를 내장합니다.

```text

│   └── icon-128.png

│   ├── background/
│   │   └── service-worker.js  # 백그라운드 서비스 워커 (캐시 삭제 & 리로드 엔진 & 브릿지 리스너)
│   └── options/               # 모던 3탭 사용자 정의 옵션 페이지
│       ├── options.html       # 대시보드 마크업

└── README.md
```

## 3. 로컬 설치 방법 (개발자 모드)

1. 크롬 브라우저를 열고 주소창에 `chrome://extensions`를 입력합니다.
2. 우측 상단의 **개발자 모드 (Developer mode)** 토글을 활성화합니다.
3. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다 (Load unpacked)** 버튼을 클릭합니다.
4. 아래 디렉터리를 선택합니다:
   ```text
   /Users/paul/sandbox/sre-toolbox/chrome/keep-login-hard-reload
   ```
5. 브라우저 우측 상단 퍼즐 조각(확장 프로그램 목록) 아이콘을 눌러 **KeepLogin Hard Reload**를 핀(고정)해 두면 편리합니다.

## 4. 사용 방법

### 1) 현재 탭 강력 새로고침
- **단축키 실행**:
  - Mac: **`Option + R (⌥ + R)`**
  - Windows / Linux: **`Alt + R`**
- **원클릭 실행**:
  - 브라우저 상단 툴바의 파란색 리로드 아이콘을 마우스 좌클릭합니다.
  - 화면 상단에 캡슐 토스트가 즉시 노출된 뒤, 캐시 삭제 후 새로고침됩니다.

### 2) 전체 브라우저 캐시 비상 청소 (Sandbox Clean)
- 모든 사이트의 로그인 세션(쿠키, 스토리지)은 안전하게 유지한 채 브라우저 전체의 정적 캐시만 일괄 초기화합니다.
- **복합 단축키**:
  - Mac: **`Option + Shift + C (⌥ + ⇧ + C)`**
  - Windows / Linux: **`Alt + Shift + C`**
- (또는 옵션 페이지의 탭 3에서 큼직한 '전체 브라우저 캐시 즉시 비우기' 버튼 클릭)

## 5. 모던 옵션 설정 대시보드

툴바 아이콘을 **마우스 우클릭**한 뒤 **옵션(Options)**을 선택하면 3탭 대시보드가 열립니다:

- **테마 전환**: 상단에서 `[시스템 / 다크 / 라이트]` 테마를 자유롭게 선택할 수 있습니다.
- **탭 1 (현재 탭 설정)**: HTTP 캐시, 서비스 워커, 캐시 스토리지, 자동 리로드, 인-페이지 HUD 표시 여부를 개별 토글합니다.
- **탭 2 (열린 탭 & 도메인 관리)**:
  - **Live Open Tabs**: 현재 브라우저에 열려 있는 모든 웹 탭의 도메인을 파싱하여, 원하는 사이트들만 체크 후 일괄 캐시 삭제.
  - **Managed Sites**: 자주 테스트하는 도메인(예: `http://localhost:3000`, `grafana` 등)을 즐겨찾기처럼 등록해 두고 원클릭 일괄 캐시 삭제.
- **탭 3 (자동화 & 비상 청소)**:
  - **백그라운드 스케줄러**: 대상 사이트를 선택하고 분 단위(예: 10분)를 입력하면 새로고침 없이 백그라운드에서 캐시만 조용히 정기 삭제. 타 탭 시청 중에도 우측 상단 툴바에 보라색 `AUTO` 배지와 크롬 OS 알림이 발생합니다.
  - **Sandbox Clean**: 전체 캐시 일괄 삭제 및 단축키 안내.

## 6. AI 에이전트 및 외부 자동화 연계 (`tools/bridge.py`)

프론트엔드 빌드 워처(Vite/Webpack) 또는 AI 코딩 에이전트가 소스코드를 수정한 뒤, 브라우저를 직접 건드리지 않고 **터미널 명령어 한 줄로 브라우저 새로고침을 자동 트리거**할 수 있습니다.

- **지원 OS**: macOS, Linux, Windows (Python 3 표준 라이브러리만 사용, 별도 pip 설치 불필요)

### 실행 방법
1. **브릿지 서버 구동 (백그라운드 1회 실행)**:
   ```bash
   python3 tools/bridge.py --server
   ```
2. **에이전트 또는 터미널에서 리프레시 트리거**:
   ```bash
   # 활성 탭 즉시 새로고침
   python3 tools/bridge.py --trigger
   # 또는 curl로 호출
   curl -X POST http://127.0.0.1:8765/reload

   # 특정 도메인 타겟 새로고침
   curl -X POST "http://127.0.0.1:8765/reload?origin=http://localhost:3000"
   ```

## 7. 단축키 변경 방법

1. 크롬 주소창에 `chrome://extensions/shortcuts`를 입력합니다.
2. **KeepLogin Hard Reload** 항목에서 원하는 단축키 조합을 자유롭게 수정하여 충돌을 방지할 수 있습니다.
